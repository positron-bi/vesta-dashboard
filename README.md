# داشبورد وب مالی وستا

نسخهٔ وب گزارش `vesta.pbix` با سه صفحهٔ **نمای کلی**، **سود و زیان** و **بودجه و عملکرد** است. طراحی صفحه‌ها از ساختار گزارش Power BI گرفته شده است. ریز اسناد حسابداری در این نسخه منتشر نمی‌شود.

## اجرا

این پوشه برای انتشار در ریپوی `positron-bi/vesta-dashboard` آماده است. در GitHub Pages شاخهٔ `main` و پوشهٔ ریشه را انتخاب کنید؛ فایل `index.html` صفحهٔ اصلی است.

برای پیش‌نمایش محلی، آن را از طریق یک وب‌سرور باز کنید، نه با دوبارکلیک روی فایل HTML:

```powershell
python -m http.server 4173
```

سپس `http://127.0.0.1:4173` را باز کنید.

## به‌روزرسانی داده

دادهٔ نمایشی در `data/dashboard-data.json` از مدل PBIX استخراج شده است. برای رفرش واقعی باید دادهٔ جدید استخراج و commit شود؛ اجرای محاسبات پایتون روی همان فایل قدیمی، اطلاعات تازه تولید نمی‌کند. برنامه‌ریزی خودکار ساعت ۳ صبح هنوز پیاده‌سازی نشده است.


منطق محاسباتی گزارش از Power BI به پایتون منتقل شده است؛ راهنما و کد آن در پوشهٔ `python/` قرار دارد.

در صفحهٔ بودجه، عملکرد فقط با بودجهٔ همان سال مقایسه می‌شود. ماه‌های بدون دادهٔ واقعی در نمودار خالی می‌مانند.
